# 基于51单片机的俄罗斯方块游戏

基于 51 单片机（STC89C52 / AT89S52）设计的俄罗斯方块游戏课程设计完整资料，包含 C 语言源码、Keil 工程、原理图与 PCB、Proteus 仿真、设计报告、元件清单与芯片资料。

## 功能特性

- 经典俄罗斯方块玩法：方块生成、旋转、左右移动、快速下落、消行计分
- 12864 液晶（128X64）图形显示，实时显示游戏界面与得分
- 按键控制：开始/暂停、方向移动、旋转、加速下落
- 行消除计分机制，难度随消行数提升

## 使用说明

### 1. 编译源码（Keil）

- 用 Keil μVision 打开 `1-程序/工程文件/obj.uvproj`
- 编译后生成的固件位于 `1-程序/hex文件/obj.hex`

### 2. 仿真运行（Proteus）

- 用 Proteus 打开 `5-仿真/` 下的工程（如 `128X64.DSN`）
- 加载 `obj.hex` 固件后运行仿真，即可在 12864 液晶上看到游戏画面

### 3. 实物烧录

- 使用 STC89C52 / AT89S52 单片机，将 `obj.hex` 通过烧录器/串口工具写入芯片
- 按原理图连接 12864 液晶、按键等外围电路
